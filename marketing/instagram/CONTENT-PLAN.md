# Vishwaship Instagram content plan

Daily: 2–3 carousels (1080×1350). Rotate the three pillars so every day covers at least two.

- **S = Shipping**: courier rates, COD, RTO/NDR, cargo, tracking
- **G = Growth Package (D2C)**: own website + domain, Meta Pixel / GA4 / Google Ads conversion, ads and creatives, account manager
- **P = Panel**: orders, inventory, P&L, expenses, GST invoices, reports

## How to make a post
1. Copy a JSON in `posts/<date>/` and change the text (`*word*` turns orange).
2. Run `node marketing/instagram/build.js marketing/instagram/posts/<date>/<name>.json`.
3. The slides and `caption.txt` appear in the folder of the same name.
